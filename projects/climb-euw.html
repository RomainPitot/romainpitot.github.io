Overview

A progress tracker for League of Legends ranked play. It follows each game, recomputes the rank from LP changes, detects play sessions and generates a structured recap meant to be pasted into an AI coach. Everything stays in the browser (localStorage): no backend, no account, with JSON export and import. Open source, deployed on GitHub Pages.

Highlights

  • Rank engine driven by LP changes, game by game
  • Session detection and structured coach recap
  • No backend: data stays in the browser, JSON export/import
