Global InvasionMission/MissionClock.cs

Mission state machine

Day → Night → Dawn → Debrief, on deadlines, with no dependency on Unity or the network.

Mission/MissionClock.cs
// Day → Night → Dawn → Debrief → Over, each on a deadline.
//
// Plain C# with the time passed in, like ContractVoteTally: the network
// wrapper (MissionManager) feeds it the server clock, and the tests feed it
// whatever numbers they want.
public class MissionClock
{
    public struct Durations
    {
        public double day;
        public double night;
        public double dawn;
        public double debrief;
    }

    readonly Durations durations;

    public MissionPhase Phase { get; private set; } = MissionPhase.None;

    // Anyone can press the truck button, even far too early: that's the joke
    // (GDD 13.1). Only meaningful during the day.
    public bool RequestNight(double now)
    {
        if (Phase != MissionPhase.Day) return false;

        Enter(MissionPhase.Night, now);
        return true;
    }

    // Moves at most one phase per call. Returns true when the phase changed.
    public bool Tick(double now)
    {
        if (Phase == MissionPhase.None || Phase == MissionPhase.Over) return false;
        if (now < Deadline) return false;

        Enter(Next(Phase), now);
        return true;
    }

    public double SecondsLeft(double now)
    {
        if (Phase == MissionPhase.None || Phase == MissionPhase.Over) return 0;
        return now >= Deadline ? 0 : Deadline - now;
    }
}

Why it is written this way. The rules are plain C# and receive the time as a parameter. The network wrapper feeds it the server clock; the tests feed it any number they want, so the whole mission loop is tested without launching a session.

Global InvasionMission/NestDraw.cs

Seeded nest & clue draw

Picks where the nest is this run and which clues (and decoys) are on site.

Mission/NestDraw.cs
// Picks where the nest is this time and which clues are on site.
// Plain C# with the randomness injected, so the draw is testable and the
// server is the only one rolling dice.
public static class NestDraw
{
    public struct Result
    {
        public int nest;
        public List<int> clues;
    }

    // clueNest[i] = index of the nest clue i leads to, or -1 for a decoy.
    // Every clue of the drawn nest is shown (no single clue is enough, GDD 4:
    // they have to be crossed), plus a few decoys so a clue alone proves nothing.
    public static Result Draw(Random rng, int nestCount, IList<int> clueNest, int decoysToShow)
    {
        Result result = new Result { nest = -1, clues = new List<int>() };
        if (rng == null || nestCount <= 0 || clueNest == null) return result;

        result.nest = rng.Next(nestCount);

        List<int> decoys = new List<int>();
        for (int i = 0; i < clueNest.Count; i++)
        {
            if (clueNest[i] == result.nest) result.clues.Add(i);
            else if (clueNest[i] < 0) decoys.Add(i);
        }

        // Partial Fisher-Yates: the first n decoys end up random.
        int take = Math.Min(Math.Max(0, decoysToShow), decoys.Count);
        for (int i = 0; i < take; i++)
        {
            int j = rng.Next(i, decoys.Count);
            (decoys[i], decoys[j]) = (decoys[j], decoys[i]);
            result.clues.Add(decoys[i]);
        }

        result.clues.Sort();
        return result;
    }
}

Why it is written this way. Randomness is injected, so the draw is reproducible in tests and only the server rolls the dice. Decoys are chosen with a partial Fisher–Yates shuffle so no single clue is enough on its own.

Global InvasionSwarm/SwarmSim.cs

Local swarm, events on the wire

Hundreds of roaches simulated on every PC; only events cross the network.

Swarm/SwarmSim.cs
// What the swarm needs to know about the level. Real game: physics colliders
// (PhysicsSwarmWorld). Tests: a fake.
public interface ISwarmWorld
{
    // Can a roach crawling at `height` go from A to B in a straight line?
    bool Blocked(Vector2 from, Vector2 to, float height, out Vector2 normal);

    // Height of the highest surface at p below `probeTop` (floor = 0).
    float SurfaceHeight(Vector2 p, float probeTop);
}

// The cockroach swarm, simulated on every PC.
//
// Only events travel over the network: "N roaches appear here" (seeded, so
// every PC places them the same way), "kill what's in this cone", "kill what's
// in this circle". After that each PC moves its own roaches; small
// differences between PCs don't matter for a crowd.
//
// Plain C# on arrays, no per-roach objects: hundreds must stay cheap.
public class SwarmSim
{
    public const int Capacity = 400;

    public struct Settings
    {
        public float wanderSpeed;
        public float fleeSpeed;
        public float playerFearRadius;   // roaches flee agents and UV light...
        public float boldFraction;       // ...except the bold ones that chase them
        public float climberFraction;    // share that climbs the furniture they bump into
        public float maxClimb;           // furniture yes, walls no
    }
}

Why it is written this way. The level is hidden behind an interface so the real game uses physics colliders and the tests use a fake. Data is stored in arrays rather than objects: I measured 0.25 ms per step for 300 roaches.

Turret prototype (private repo)TurretScript.cs

MOBA-style turret targeting

A small early prototype: creeps are targeted before the player, and a locked target is never swapped.

TurretScript.cs
// Prototype: a MOBA-style turret. Creeps are targeted before the player,
// and a locked target is never swapped while it stays in range.
public class TurretScript : MonoBehaviour
{
    public Transform turretHead;
    public float rotationSpeed = 5f;
    public float fireRate = 1f;        // shots per second

    private Transform target;

    void OnTriggerEnter(Collider other)
    {
        // Already locked on: keep the target.
        if (target != null) return;

        // Creeps first...
        if (other.CompareTag("Creeps"))
        {
            target = other.transform;
            return;
        }

        // ...and the player only if nothing else is in range.
        if (other.CompareTag("Player"))
            target = other.transform;
    }

    void OnTriggerExit(Collider other)
    {
        if (other.transform == target)
            target = null;             // target left the zone: free the turret
    }

    void AimAtTarget()
    {
        Vector3 direction = target.position - turretHead.position;
        Quaternion lookRot = Quaternion.LookRotation(direction);
        turretHead.rotation = Quaternion.Slerp(
            turretHead.rotation, lookRot, rotationSpeed * Time.deltaTime);
    }
}

Why it is written this way. Small on purpose. It shows how I start: one clear rule per piece of code, written first and tuned after. Newer work (above) is where the structure and tests are.
