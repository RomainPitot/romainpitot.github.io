About Me

Full profile

I'm Romain, a developer based in Toulouse. Two years of work-study at Masseka Games Studio on mobile games, a Master's in game development, five game jams — and a co-op Steam game I'm building solo, with lobbies, netcode and game rules covered by tests.

Jams taught me to finish something in 48 hours; studio work taught me to maintain someone else's code.

Unity and C# are my daily tools. I have also shipped a React web app and a Python Windows tool, so I am open to any developer role, not only games.
