About Me

Unity / C# developer

Toulouse, FR  ·  MSc Game Development  ·  2 years at Masseka Games Studio

I'm Romain. I write Unity and C#, and I like turning a game rule into code that can be tested.

I spent two years in work-study at Masseka Games Studio in Toulouse, mostly on mobile games: migrating Kissoro from Unity 2018 to 2022, fixing bugs and making the UI adapt to different screens on Vaudoo (now at 1k+ downloads on Google Play), reviving an abandoned prototype on my own, and adapting a game to The Sandbox's constraints.

Outside the studio I took part in five game jams, and I am building Global Invasion alone: a Steam co-op game with lobbies, Netcode for GameObjects and about eighty unit tests. I also made a React web app (CLIMB.EUW) and a Python Windows tool that work together, which is why I am open to any developer role and not only games.

How I work

  • Game rules in plain C# with time and randomness passed in, so they can be tested without launching the game. Network and engine classes stay thin.
  • I use AI assistants (Claude Code) as a pair programmer. I decide the design, review what comes back and test it. Where a project relies on AI tools, as in On Air, its page says so.
  • Small commits, one branch per feature, and a written plan before a change.

Based in France — Open to remote & relocation
